Laboratorio di Algoritmi e Strutture Dati

Gli esercizi svolti sono estratti a sorte sulla base del programma svolto. In questo caso:
 - Si vogliono confrontare modi diversi per costruire alberi binari di ricerca: BST, AVL, RBT;
 - Si vogliono confrontare gli algoritmi di ordinamento QuickSort e CountingSort.

Per il primo esercizio sono stati realizzati il programma di testing in python (Test BST), che include grafici mostranti l'andamento temporale, e una relazione in latex che confronta i risultati ottenuti con quelli attesi.

Per il secondo esercizio è stato realizzato un Notebook che unisce codice e teoria.
